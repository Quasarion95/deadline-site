# Deadline — сайт и демо

Публичная часть проекта **Deadline**: лендинг и кликабельный прототип приложения.

> Руководитель диктует поручение голосом. Система превращает его в задачу
> с исполнителем, сроком и проверяемым результатом — и следит, чтобы работа
> дошла до конца.

## Посмотреть

Сайт: https://quasarion95.github.io/deadline-site/
Демо: https://quasarion95.github.io/deadline-site/app/

Локально — без установки, сборки и сервера:

```bash
open index.html
```

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Лендинг с формой заявки на доступ |
| `app/` | Кликабельный прототип приложения |
| `assets/css/site.css` | Стили лендинга |
| `assets/css/app.css` | Стили прототипа |
| `assets/js/site.js` | Отправка заявки с лендинга |
| `assets/js/app.js` | Вся логика и отрисовка прототипа |

Чистые HTML, CSS и JS без фреймворков и зависимостей.

## Важно про демо

Прототип работает **на вымышленных данных, прямо в браузере**. Ни сервера,
ни базы, ни настоящего распознавания речи за ним нет: голосовой ввод —
имитация, заранее записанная фраза. Состояние живёт в памяти вкладки,
обновление страницы всё сбрасывает.

Это демонстрация продуктовой идеи, а не работающий продукт.

## Куда уходят заявки

Задаётся двумя атрибутами формы в `index.html`: `data-endpoint` (адрес сервиса
форм) или `data-email` (запасной путь через почтовую программу). Пока не
заполнено ни одно — форма честно говорит, что приём заявок не подключён,
и не делает вид, что заявка ушла.

## Выкладка

Автоматическая, при пуше в `main` — GitHub Actions, файл
`.github/workflows/pages.yml`. Занимает около минуты.
